A one-line out-of-office reply: the writer is away until Monday and left the calendar in charge — and the calendar has already rescheduled the return twice and now insists the writer lives in Q3.

## The line

> I'm away until Monday. My replacement is my calendar, which has already rescheduled my return twice and now insists I live in Q3.

The joke is in the turn: the setup sounds like a normal away message, then the punchline reframes it — the tool that was supposed to manage the writer's time now manages the writer, rescheduling the return and relocating the writer to a fiscal quarter. It reads like a real away message a person would be glad to switch on, with no beach, no inbox backlog, and no "limited access to email".
